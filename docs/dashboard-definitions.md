# Dashboard Definitions

## API Dashboard
- Requests per minute
- `5xx` error rate
- Authorization denials
- Webhook signature failures
- Webhook rate-limit rejections
- Sync success vs failure count

## Worker Dashboard
- `fps_in`
- `fps_processed`
- `frames_dropped`
- `queue_depth`
- `decode_latency_ms`
- `detect_latency_ms`
- `embed_latency_ms`
- `match_latency_ms`
- `reconnect_count`

## Correlation Dashboard
- Candidate events consumed
- Incidents created
- Incidents suppressed by cooldown
- Incident review confirmations
- Incident review dismissals
